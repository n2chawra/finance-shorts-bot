Finance Shorts Uploader: user flow

There is one user: the channel owner. Flow A happens once; flows B and C run automatically every day.

A · One-time authorisation (owner)

A1Owner runs the sign-in command

On their own computer.

→
A2Google consent screen

Owner chooses their channel and grants upload, read and analytics access.

→
A3Refresh token stored

Saved as an encrypted secret in the owner's private repository. Never shown.

→
A4Revoke any time

myaccount.google.com/permissions removes access immediately.

B · Daily upload (automatic)

B1Video ready in the queue

Original animated Short, checked for numbers, facts and visuals.

→
B2Publish job, 10:07 IST

Skips if uploads are paused or today's slot is used. One per day.

→
B3videos.insert

Private, publishAt 7:07 PM IST, category Education, not made for kids.

→
B4YouTube publishes at 7:07 PM

videos.list later confirms it is public.

C · Daily analytics and owner review (automatic + owner)

C1reports.query, 08:47 IST

Own channel only: views, likes, comments, subscribers, average view %.

→
C2Stored privately

All stored days refreshed daily; unrefreshable data deleted after 30 days.

→
C3Private dashboard

Owner sees the queue, upload status and performance. Can pause uploads.

No other users, no public sign-up, no YouTube data shown to anyone else. Policies: n2chawra.github.io/finance-shorts-site
