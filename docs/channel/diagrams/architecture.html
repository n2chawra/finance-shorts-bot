Finance Shorts Uploader: architecture

Personal tool for the channel "Money in 60". One owner, no other users. YouTube API calls are only made by the two daily jobs in GitHub Actions.

1 · Make the video (no YouTube API)
2 · Owner's private infrastructure
3 · YouTube API Services

Scheduled generation run

Picks a topic, writes the on-screen script, checks every number with code, has the facts and the visuals reviewed.

Renderer (own code)

Draws the animation frame by frame and synthesises the music and sound effects. No third-party footage or music.

Output

video.mp4 (under 60 s, 1080×1920), thumbnail, title, description and tags.

Private GitHub repository

Stores the video files and metadata. Holds the OAuth refresh token as an encrypted Actions secret.

Publish job daily

10:07 IST: takes the next video and uploads it, private with publishAt 7:07 PM IST. One upload per day, never more.

Stats job daily

Reads the channel's own analytics. Re-fetches all stored days every run; data it cannot refresh for 30 days is deleted.

Private database + private dashboard

Queue, upload status and analytics, visible only to the owner.

YouTube Data API v3

videos.insert (one per day) · videos.list (is it public yet?) · channels.list (which channel)

YouTube Analytics API

reports.query for the owner's own channel: daily views, likes, comments, subscribers, average view %

Owner's YouTube channel

"Money in 60". YouTube publishes each video at its publishAt time.

The owner signs in with Google OAuth once (scopes: youtube.upload, youtube.readonly, yt-analytics.readonly). Access can be revoked at any time at myaccount.google.com/permissions. Homepage, privacy policy and terms: n2chawra.github.io/finance-shorts-site
