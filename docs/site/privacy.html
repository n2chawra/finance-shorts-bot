Privacy Policy

Finance Shorts Uploader · Last updated 14 October 2026 · Home · Terms of Service

Who uses it

Finance Shorts Uploader is a personal tool operated by its owner for their own YouTube channel. It has no other users and offers no sign-up.

What it accesses

Using Google OAuth, and only with the owner's consent, it uses these YouTube permissions on the owner's own channel:

  • Upload videos (youtube.upload): to publish the owner's videos.
  • Read the channel (youtube.readonly): to confirm which channel is connected and whether an uploaded video is public.
  • Read YouTube Analytics (yt-analytics.readonly): daily views, likes, comments, subscribers gained and average view percentage for the channel's own videos.

It does not access any other person's account or data, and it does not collect personal information about viewers.

How the data is used and stored

The OAuth refresh token is stored as an encrypted secret in the owner's private GitHub repository and is used only to make the API calls above. Video details and the analytics numbers are stored in the owner's private database and shown only on the owner's private dashboard. Nothing is sold, shared or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data retention and deletion

  • Analytics numbers are refreshed from YouTube every day. Data that cannot be refreshed for 30 days (for example because access was revoked) is deleted automatically.
  • Analytics older than 365 days are deleted automatically.
  • Video details (title, description, publish time, YouTube video ID) are kept while the video is managed by the tool and deleted on request.
  • The owner can delete all stored YouTube data at any time. Any deletion request sent to the contact address below is completed within 7 days.

Revoking access

Access can be removed at any time from your Google account's security settings at security.google.com/settings/security/permissions. After access is revoked, the tool can no longer upload or read analytics, and stored analytics are deleted within 30 days as described above.
